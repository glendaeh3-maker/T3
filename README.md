OPERACIÓN EXTRACCIÓN : Sobrevive al Apocalipsis – VIDEOJUEGO FPS 3D:

Juego en primera persona desarrollado con la biblioteca Three.js, en la cual nuestro objetivo como supervivientes es cruzar una calle infestada de zombis, saber administrar nuestra municiar y llegar a la zona final sin morir en el proceso.

Sin necesidad de abrir el visual studio code puedes presionar este vinculo que abre tu navegador de confianza

https://glendaeh3-maker.github.io/T3/

y jugar tranquilamente!

Controles:
Teclas W,A,S,D son de movimiento
Mouse es nuestra mira
Clic izquierdo para disparar
R para recargar
1/2 Para cambiar entre pistola y escopeta
F Encender o apagar la linterna
E Interactuar (solo con la puerta)
Esc Pausa

Objetivo:
Atravesar una oscura y peligrosa calle hasta llegar a tu zona de extracción, para completar tu mision, pero cuidado, tienes demasiados zombies rodeandote, si uno te alcanza automaticamente pierdes, asi que no te confies.

Caracteristicas:
- Inicias con dos armas (pistola y escopeta), con municion inicial
- Municion limitada, tienes que administrar bien tus recursos
- Los zombis tienen comportamiento, si te acercas a ellos estos comenzaran a acercarse a ti y a atacarte, algunos corren
- Hay 3 modelos de zombis (1 con animacion implementada y 2 con animaciones por defecto)
- Para sentir las vibras del juego se agrego una biblioteca de sonidos
- Multiples escenarios con modelos implementados de Sketchfab
- El ambiente esta inspirado en silent hill, resident evil y left 4 dead

Si el link falla (lo dudo), puedes abrirlo desde Visual Studio Code ejecutando el index.html con Live Server

Tecnologias usadas:
- Three.js: graficos 3D, carga de modelos(GLTFLoader), controles en primera persona (PointerLockControls) y audio
- JavaScript, HTML Y CSS
